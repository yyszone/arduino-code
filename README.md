# ESP32C3 智能风扇电源控制器 (v3.6)

这是一个功能完备的、基于 ESP32-C3 的智能风扇控制器解决方案。它通过一个美观的Web界面，集成了PWM风扇调速、RPM监测、INA219电源监控、继电器定时任务、智能电源管理以及功耗统计等多种功能。

### ✨ 核心功能

*   **网页UI控制**: 提供美观、自适应的网页控制面板，可在手机或电脑上访问。
*   **PWM风扇调速**: 通过网页滑块精确控制4-Wire PWM风扇的转速。
*   **转速实时监测**: 读取风扇的转速（Tach/RPM）信号并在网页上显示。
*   **电源参数监控**: 使用 INA219 传感器实时监测负载的 **电压(V)、电流(mA)和功率(mW)**。
*   **七天电量统计**: 在网页下方以条形图形式，直观展示包括当天在内的最近七天每日总功耗 (单位Wh)，数据持久化保存，重启不丢失。
*   **继电器智能控制**:
    *   **手动控制**: 通过网页按钮随时开启或关闭继电器。
    *   **智能电源管理**:
        *   **低压保护**: 当电池电压低于设定阈值时，自动关闭继电器并锁定1小时以保护电池。
        *   **高压自启**: 当检测到电压高于设定阈值（代表电量充足）时，自动开启继电器。
        *   **自动恢复**: 在锁定1小时后，系统会重新检查电压，如果已恢复则自动开机。
        *   **管理员覆盖**: 允许用户在锁定期间通过网页按钮 **手动强制开启** 继电器。
*   **增强的停机信息**: 在触发低压保护时，除了显示上次运行的时长，还会记录并显示具体的 **停止时间点**。
*   **定时任务**: 可通过网页设置最多2个定时开启或关闭的任务。
*   **OTA 在线更新**: 无需连接数据线，通过网页即可上传新固件进行更新。
*   **mDNS 支持**: 可以通过 `http://esp32-smart-fan.local` 这样的友好域名访问设备。

### 硬件清单

1.  **主控**: ESP32-C3 开发板。
2.  **电源传感器**: INA219 电流/电压传感器模块。
3.  **开关**: 5V 继电器模块。
4.  **风扇**: 4-Wire PWM 调速风扇 (12V或5V均可，取决于您的供电)。
5.  **电源**:
    *   一个用于 ESP32 的 MicroUSB/Type-C 电源。
    *   一个用于风扇和继电器的独立电源 (例如12V电源适配器或18650锂电池)。
6.  **杜邦线**若干。

### 硬件接线

#### 控制线路

| ESP32-C3 引脚 | 连接到 | 设备/模块 | 功能描述 |
| :--- | :--- | :--- | :--- |
| **VIN/5V** | ---> | 继电器模块 **VCC** | 为继电器提供 5V 工作电源 |
| **GND** | ---> | 继电器模块 **GND** | 公共地线 |
| **GPIO 1** | ---> | 继电器模块 **IN** | **控制继电器开关** |
| **3V3** | ---> | INA219 **VCC** | 为 INA219 传感器供电 |
| **GND** | ---> | INA219 **GND** | 公共地线 |
| **GPIO 8 (SCL)**| ---> | INA219 **SCL** | I2C 时钟线 |
| **GPIO 10 (SDA)**| ---> | INA219 **SDA** | I2C 数据线 |
| **GPIO 5** | ---> | 风扇 **PWM** 线 | PWM 调速信号 |
| **GPIO 4** | ---> | 风扇 **Tach (测速)** 线 | 读取风扇转速脉冲 |

#### 主电源线路 (串联接法)

1.  **[风扇电源 +]**  -->  **INA219 Vin+**
2.  **INA219 Vin-**  -->  **继电器 COM (公共端)**
3.  **继电器 NO (常开端)**  -->  **风扇电源正极 `+`**
4.  **[风扇电源 -]** 与 **风扇电源负极 `-`**  -->  连接到一起

### ⚠️ 最重要的概念：共地 (Common Ground)

**这是整个项目成败的关键！** 当您使用 **两套独立电源** 时（一套通过USB给ESP32供电，另一套给风扇和继电器供电），必须将它们的“地线”连接在一起。

**如何实现共地？**
非常简单：**用一根杜邦线，将 ESP32 开发板上的任意一个 `GND` 引脚，连接到风扇电源的负极 (`-` 或 `GND`) 上。**

# ESP8266 网页定时插座

这是一个基于 ESP-01S (或任何其他 ESP8266 开发板) 的极简智能插座项目。它旨在以最低的硬件成本，提供一个功能实用的网页控制定时器。

### ✨ 核心功能

*   **网页UI控制**: 提供一个简洁的网页界面，用于所有操作。
*   **手动控制**: 通过网页按钮可以随时手动开启或关闭继电器。
*   **多任务定时**: 支持添加多达20个“开机”和“关机”的定时任务。
*   **本地时间同步**: 可以通过网页将控制器的时间与您的浏览器时间同步，无需连接互联网NTP服务器。
*   **OTA 网页更新**: 内置了 `ESP8266HTTPUpdateServer`，可以通过访问 `/update` 页面来上传新固件，实现无线升级。

### 硬件清单

1.  **主控**: ESP-01S 或其他ESP8266开发板 (如 Wemos D1 Mini, NodeMCU)。
2.  **开关**: 5V **低电平触发** 的继电器模块。
3.  **电源**: 5V 电源，用于同时给ESP8266和继电器供电。
4.  **下载器**: 如果使用ESP-01S，需要一个USB转串口的下载器。
5.  **杜邦线**若干。

### 硬件接线 (以 ESP-01S 为例)

| ESP-01S 引脚 | 连接到 | 设备/模块 | 功能描述 |
| :--- | :--- | :--- | :--- |
| **VCC (3.3V)** | ---> | (由下载器或稳压模块提供) | 为 ESP-01S 供电 |
| **GND** | ---> | 继电器模块 **GND** | **公共地线** |
| **GPIO 0** | ---> | 继电器模块 **IN** | 控制继电器 (低电平有效) |
| **5V (电源)** | ---> | 继电器模块 **VCC** | 为继电器提供 5V 工作电源 |

**注意**: 本项目代码中的 `digitalWrite(relay, LOW);` 是为了**开启**继电器，这表明它适配的是**低电平触发**的继电器模块。如果您的模块是高电平触发，请将代码中的 `LOW` 和 `HIGH` 对调。

### 软件与配置

1.  **Arduino IDE 设置**:
    *   在“首选项”的“附加开发板管理器网址”中添加 ESP8266 的支持：`http://arduino.esp8266.com/stable/package_esp8266com_index.json`
    *   在“开发板管理器”中搜索并安装 `esp8266`。
    *   选择您的开发板型号，例如 `Generic ESP8266 Module` 或 `LOLIN(WEMOS) D1 R2 & mini`。

2.  **配置代码**:
    *   打开 `sp8266.ino` 文件。
    *   修改顶部的WiFi信息：
        ```cpp
        WiFi.begin("你的WiFi名称", "你的WiFi密码");
        ```

3.  **上传与使用**:
    *   连接ESP8266并上传代码。
    *   打开串口监视器（波特率115200）查看IP地址。
    *   通过浏览器访问该IP地址进行控制。
    *   若要更新固件，请访问 `http://[IP地址]/update`。

# ESP32C3 基础风扇控制器 (带 Web UI + OTA)

这是一个基于 ESP32-C3 的基础风扇控制器项目。它专注于实现PWM风扇的核心控制与监测功能，并通过一个现代化的网页界面进行交互。

### ✨ 核心功能

*   **网页UI控制**: 提供一个美观、简洁的网页控制面板。
*   **PWM风扇调速**: 通过网页上的滑块，实时调节4-Wire PWM风扇的占空比，从而控制转速。
*   **转速实时监测**: 读取风扇的Tach (RPM) 信号，并将实时转速显示在网页上。
*   **系统信息显示**: 在网页上展示芯片型号、CPU频率、内存使用情况和IP地址等系统状态。
*   **OTA 在线更新**: 无需物理连接，通过网页即可方便地上传新固件进行无线升级。
*   **mDNS 支持**: 可以通过 `http://[hostname].local` 格式的友好域名访问设备，无需记忆IP地址。

### 硬件清单

1.  **主控**: ESP32-C3 开发板。
2.  **风扇**: 4-Wire PWM 调速风扇 (支持5V PWM信号)。
3.  **电源**:
    *   一个用于 ESP32 的 MicroUSB/Type-C 电源。
    *   一个独立的风扇电源（如果风扇工作电压不是5V）。
4.  **杜邦线**若干。

### 硬件接线

| ESP32-C3 引脚 | 连接到 | 设备/模块 | 功能描述 |
| :--- | :--- | :--- | :--- |
| **GPIO 5** | ---> | 风扇 **PWM** 控制线 | 发送PWM调速信号 |
| **GPIO 4** | ---> | 风扇 **Tach (测速)** 线 | 读取风扇转速脉冲 |
| **GND** | ---> | 风扇 **GND** 线 | 公共地线 |
| **(外部电源)** | ---> | 风扇 **VCC** 电源线 | 为风扇供电 |

**重要**: 如果您使用独立的电源为风扇供电，请务必将 **风扇电源的负极 (GND)** 与 **ESP32-C3的GND** 连接在一起，以确保信号电平正确（共地原则）。

### 软件与配置

1.  **Arduino IDE 设置**:
    *   在“首选项”的“附加开发板管理器网址”中添加 ESP32 的支持：`https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
    *   在“开发板管理器”中搜索并安装 `esp32`。
    *   选择开发板为 `ESP32C3 Dev Module`。
    *   **重要**: 在“分区方案(Partition Scheme)”中，选择一个带OTA的选项，例如 `Default with OTA`。

2.  **配置代码**:
    *   打开 `esp32fan.ino` 文件。
    *   修改顶部的用户配置部分：
        ```cpp
        const char* ssid       = "你的WiFi名称";
        const char* password   = "你的WiFi密码";
        const char* deviceName = "esp32c3-fan-yys"; // 可自定义设备主机名
        ```

3.  **上传与使用**:
    *   连接ESP32-C3并上传代码。
    *   打开串口监视器（波特率115200）查看IP地址或mDNS地址。
    *   在浏览器中访问该地址即可开始控制。



### 4. 用于 `esp8266_AuraFan` 文件夹的 README

**ESP8266 智能风扇 & 多路灯带网页控制器 (v1.3)**

AuraFan 是一个功能强大且高度可定制的 ESP8266 项目，它将精确的 4-Pin PWM 风扇控制与多路 WS2812B 可编程灯带控制相结合，并通过一个优雅、现代的网页界面进行统一管理。项目代码经过精心重构，实现了终极的可扩展性——您只需在文件顶部的配置区进行简单的修改，即可轻松增删灯带，无需触碰任何核心逻辑代码。

AuraFan 采用了一个明亮、柔和的 "Butterfly" 主题。界面卡片使用了精致的玻璃拟态 (Glassmorphism) 效果，配合优雅的紫蓝色渐变背景，为您在电脑或手机上提供一流的视觉和操作体验。

## ⚙️ 软件与固件设置

### 1. 准备 Arduino IDE

*   **安装 Arduino IDE**: 从 [官方网站](https://www.arduino.cc/en/software) 下载并安装。
*   **配置 ESP8266 开发板环境**:
    *   打开 `文件` -> `首选项`。
    *   在 "附加开发板管理器网址" 中，填入: `http://arduino.esp8266.com/stable/package_esp8266com_index.json`
    *   打开 `工具` -> `开发板` -> `开发板管理器`，搜索 `esp8266` 并安装。
*   **安装所需库**:
    *   打开 `工具` -> `管理库`。
    *   搜索并安装 `FastLED` 库。

### 2. 配置固件

将 `v1.3` 版本的代码下载并用 Arduino IDE 打开。所有您需要修改的配置项都集中在文件的最顶部。

**a. 配置 WiFi 和设备名称:**
```cpp
// --- WiFi 设置 ---
const char* ssid = "你的WiFi名称";
const char* password = "你的WiFi密码";

// --- 设备名称 ---
const char* deviceName = "esp8266-fan"; // mDNS 域名将是 http://esp8266-fan.local
```

**b. 配置风扇引脚:**
```cpp
// --- 风扇引脚 ---
const int PWM_PIN = D5;
const int TACH_PIN = D6;
```

**c. 配置 LED 灯带 (核心):**
这是本项目的最大亮点。您只需在这里定义您的灯带布局即可。

例如，如果您有 **2 条**灯带：
```cpp
#define NUM_STRIPS 2 // <--- 灯带总数量为 2

// --- 灯带 1 ---
#define STRIP1_PIN   D7
#define STRIP1_LEDS  30

#if NUM_STRIPS >= 2
// --- 灯带 2 ---
#define STRIP2_PIN   D8
#define STRIP2_LEDS  60
#endif
```

如果您只有 **1 条**灯带：
```cpp
#define NUM_STRIPS 1 // <--- 灯带总数量改为 1

// --- 灯带 1 ---
#define STRIP1_PIN   D7
#define STRIP1_LEDS  90 // 灯珠数改为您实际的数量
```

如果您想增加到 **3 条**灯带：
```cpp
#define NUM_STRIPS 3 // <--- 灯带总数量改为 3

// --- 灯带 1 ---
#define STRIP1_PIN   D7
#define STRIP1_LEDS  30

#if NUM_STRIPS >= 2
// --- 灯带 2 ---
#define STRIP2_PIN   D8
#define STRIP2_LEDS  60
#endif

#if NUM_STRIPS >= 3
// --- 灯带 3 ---
#define STRIP3_PIN   D3 // 使用一个新的引脚
#define STRIP3_LEDS  50 // 定义它的灯珠数
#endif
```

## 🚀 使用方法

1.  **上传代码**: 在 Arduino IDE 中选择正确的开发板 (如 `NodeMCU 1.0`) 和端口，然后点击上传。
2.  **获取 IP 地址**: 上传成功后，打开 `工具` -> `串口监视器` (波特率设为 115200)，等待 ESP8266 连接上 WiFi 后，会打印出设备的 IP 地址。
3.  **访问网页**:
    *   在浏览器中直接输入获取到的 IP 地址。
    *   或者，如果您的设备支持 mDNS，可以直接访问 `http://esp8266-fan.local` (或您自定义的设备名)。
4.  **开始控制**:
    *   拖动**风扇滑块**来调节风扇速度。
    *   点击**灯光按钮**来切换模式，或使用**取色器**设置静态颜色。
5.  **固件更新**:
    *   访问 `http://设备IP/update` 或点击网页上的 "固件更新" 链接。
    *   选择编译好的 `.bin` 固件文件并上传即可。

# ESP8266 智能双控触摸屏 (v4.5)

这是一个高度可靠、功能完备的 ESP8266 物联网（IoT）控制器。它以一块 ILI9341 触摸屏为核心，通过一个简洁的双按钮界面，实现了对两个独立网络设备（Home Assistant 实体和任意 HTTP 设备）的远程控制。

项目集成了优雅的网页日志系统、OTA 在线更新功能，并采用了一个经过优化的**软件待机模式**，在保证绝对可靠唤醒的前提下，通过关闭屏幕、关闭Wi-Fi并降低CPU频率，实现了显著的功耗降低。

[此处应有项目运行时的照片]

## ✨ 核心功能

*   **📱 双按钮触摸界面**: 在屏幕上提供两个清晰、独立的触摸按钮，分别控制两个不同的智能设备。
*   **🌐 双设备网络遥控**:
    *   通过 **Home Assistant API** 控制一个设备（例如开关、灯光）。
    *   通过发送 **HTTP GET 请求** 控制另一个设备（例如其他ESP模块或任何支持URL控制的设备）。
*   **💤 智能软件待机**: 经过优化的低功耗模式，比常规待机功耗更低。
    *   一分钟无操作后，自动 **关闭Wi-Fi**、**关闭屏幕控制器及背光**，并**将CPU降频至80MHz** 以最大限度节省能源。
*   **👆 触摸唤醒**: 在待机模式下，任何触摸都会**立即、可靠地**唤醒设备，恢复全部功能。
*   **📋 网页事件日志**:
    *   通过浏览器访问 `/logs` 页面，可查看带有精确时间戳的设备事件历史。
    *   日志内容包括：系统启动、待机/唤醒、Wi-Fi连接状态、触摸坐标、按钮触发动作等。
*   **☁️ OTA 在线更新**: 无需连接数据线，通过网页即可上传新固件进行更新。
*   **🕒 NTP 自动校时**: 自动从网络时间服务器同步时间，确保日志时间戳的准确性。

## 🛠️ 硬件清单

1.  **主控**: ESP8266 开发板 (例如 NodeMCU, Wemos D1 Mini)。
2.  **显示屏**: ILI9341 TFT 触摸屏模块 (2.4寸, 240x320, SPI接口, 带XPT2046触摸控制器)。
3.  **电源**: 5V MicroUSB 电源。
4.  **杜邦线** 若干。

## 🔌 硬件接线

| 组件/功能      | ESP8266 引脚 (GPIO) | 连接到屏幕模块引脚 | 功能描述                      |
| :------------- | :------------------ | :----------------- | :---------------------------- |
| **TFT 显示**   | **15 (D8)**         | `CS`               | 屏幕片选                      |
|                | **5 (D1)**          | `DC` / `RS`        | 屏幕数据/命令选择             |
|                | **4 (D2)**          | `RST`              | 屏幕复位                      |
| **触摸**       | **0 (D3)**          | `T_CS`             | 触摸芯片片选                  |
| **SPI (共享)** | **14 (D5)**         | `SCK` / `T_CLK`    | **并联**到屏幕和触摸的时钟线  |
|                | **12 (D6)**         | `MISO` / `T_DO`    | **并联**到屏幕和触摸的数据输出 |
|                | **13 (D7)**         | `MOSI` / `T_DIN`   | **并联**到屏幕和触摸的数据输入 |
| **电源**       | **3V3**             | `VCC`              | 为屏幕和触摸模块供电          |
|                | **GND**             | `GND`              | 公共地线                      |

#### 背光控制 (两种方案可选)

*   **方案一 (推荐，支持待机)**:
    *   将 ESP8266 的 **`D0` (GPIO 16)** 引脚连接到屏幕模块的 **`LED`** (或 `BL`) 引脚。本项目的代码基于此方案编写。

*   **方案二 (极简，屏幕常亮)**:
    *   将屏幕模块的 **`LED`** 引脚直接连接到 ESP8266 的 **`3.3V`** 引脚。如果采用此方案，您可以将代码中所有与 `TFT_LED` 相关的行删除。

## 🚀 使用方法

1.  **上传代码**: 在 Arduino IDE 中选择您的开发板型号 (例如 `NodeMCU 1.0`) 和端口，然后点击上传。
2.  **获取 IP 地址**: 上传成功后，打开 `工具` -> `串口监视器` (波特率设为 115200)，等待 ESP8266 连接上 WiFi 后，会打印出设备的 IP 地址。
3.  **开始使用**:
    *   **屏幕控制**: 直接点击屏幕上的按钮即可控制设备。设备将在无操作1分钟后自动进入待机模式（屏幕熄灭），再次触摸即可唤醒。
    *   **网页访问**:
        *   在浏览器中输入获取到的 IP 地址，可以访问主页。
        *   点击主页上的 **“查看事件日志”** 按钮，或直接访问 `http://[IP地址]/logs` 来查看详细的操作历史。
        *   若要更新固件，请访问 `http://[IP地址]/update`。
